# LawyerDesk 0.1.0-beta.2 — macOS ARM64 未签名预发布

这是 LawyerDesk 的手动下载测试版本，不是 LawyerCopilot，也不是上游通用 DSH Desktop 发行版。

## 变化

- 默认内置法律版 GenUI：结构化展示审查结果与后续分析请求，不将按钮点击宣称为业务执行成功。
- 默认内置只读材料侧栏：浏览当前会话工作区，预览文本、图片和 PDF，将材料引用放入输入框而不自动发送。
- 既有安装补齐内置插件；升级记录与备份受保护，启动健康确认后才清理，支持安装/启动失败及中断恢复。
- 包含此前尚未合入默认分支的 LawyerDesk 受管基础、独立数据目录与 Agent Teams 组合。

## 适用范围与安装

仅适用于 Apple Silicon Mac（ARM64）。下载文件名中的 `unsigned` 表示没有 Developer ID 签名和 Apple 公证。本次没有 Windows、Intel/universal 安装包，也不建立或修改自动更新通道。

先核对随附 SHA256SUMS，再解压 ZIP。保留现有版本与数据备份后手动选择安装位置。macOS 可能阻止未签名应用；仅在确认来源和摘要后使用系统提供的单应用允许方式，企业设备遵循组织策略。不要关闭系统整体安全检查。下载后带 quarantine 标记的 Finder 安装路径未作为自动验收覆盖，不保证免提示启动。

本版本不自动迁移 LawyerCopilot。模型站与受管市场策略仍固定；内置插件不能从公共 npm/插件市场自动替换。

## 验收与发行证据

发行前对最终构建执行受管运行时摘要检查、许可/NOTICE 检查、源码及真实未签名 app 启动检查；关键 GenUI 和材料交互使用本机 HTTP 夹具及可丢弃 home 验收。发布附件的发行记录列出确切提交、文件摘要和实际通过的检查，未运行的检查不列为通过。

这是预发布，不代表完成所有操作系统、办公文件格式、真实业务服务或生产环境的端到端验证。只读材料预览不改变原文件；PDF 原生查看器可能另外提供用户主动的打印/下载操作。
