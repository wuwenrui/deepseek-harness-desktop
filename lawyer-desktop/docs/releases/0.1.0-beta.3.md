# LawyerDesk 0.1.0-beta.3 — macOS ARM64 未签名预发布

这是 LawyerDesk 的手动下载测试版本，不是 LawyerCopilot，也不是上游通用 DSH Desktop 发行版。

## 费用与充值

模型服务中的「账户与充值」打开工作台内的费用面板。费用与充值仍是签名律师能力市场中的可选插件：用户主动安装、重启生效，不作为必装种子捆绑。未安装时显示安装说明；升级保留既有可选插件。

插件展示账户余额和消费记录，并在支持的宿主上提供发送前费用核对、确认或取消。人工充值支持微信和支付宝两种申请方式：先核对金额，再明确提交，查看申请状态并刷新余额。提交结果不明确时不会自动重试；处理状态不等于余额已到账，应核对实际余额。

费用参考仅覆盖本轮首次主请求，不是整个任务的扣费上限；后续循环、辅助调用与子代理等可能另外计费。输入区不再常驻费用提示，需要核对时才显示面板。

## 律师能力安装

安装进度显示在正在安装的能力卡片内。安装完成后的重启提示不再锁住其他能力：可以先连续安装，再一次重启让新能力生效。同一时间仍只执行一个安装操作。

## 安装与边界

仅适用于 Apple Silicon Mac（ARM64）。本次没有 Developer ID 签名、Apple 公证、Windows 或 Intel/universal 安装包，不建立或修改自动更新通道。

下载后核对 SHA256SUMS，再解压 ZIP。保留旧版本与数据备份后手动选择安装位置；不要覆盖 LawyerCopilot。macOS 可能阻止未签名应用，仅在确认来源和摘要后使用系统提供的单应用允许方式，不要关闭系统整体安全检查。带 quarantine 标记的 Finder 安装未作为自动验收覆盖。

模型站与签名市场边界不变。充值付款是用户自行决定的真实金钱操作；发行测试仅使用可丢弃本地服务、合成图片和假订单，不扫描、不付款、不发送真实 Bark 通知，也不调用真实模型。
